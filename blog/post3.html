Raspberry Pi Installation with SSH & VNC

"The Raspberry Pi 4 is a powerful, low-cost single-board computer that is widely used for various projects, from home automation to learning programming."

This comprehensive guide will walk you through setting up your Raspberry Pi 4 with remote access via SSH (Secure Shell) and VNC (Virtual Network Computing). SSH allows command-line access to the Raspberry Pi remotely, while VNC enables graphical access to the desktop environment.

Goals

  • Install Raspberry Pi OS on the Raspberry Pi 4

  • Enable SSH and VNC services for remote access

  • Provide a step-by-step guide to ensure users can connect to the Raspberry Pi remotely

Hardware and Software Requirements

Hardware

  • Raspberry Pi 4 (with 2GB, 4GB, or 8GB RAM)
  • MicroSD card (at least 8GB, Class 10 recommended)
  • Power supply (5V, 3A USB-C adapter)
  • HDMI cable (optional, if connecting a display)
  • Keyboard and mouse (optional, for local setup)
  • Computer (for flashing the MicroSD card)
  • Network connection (Ethernet or Wi-Fi)

Software

  • Raspberry Pi Imager
  • Raspberry Pi OS (formerly Raspbian)
  • SSH client (PuTTY for Windows, terminal for macOS/Linux)
  • VNC client (RealVNC Viewer)
  • MicroSD card reader

Step-by-Step Installation Guide

1 Install Raspberry Pi OS on the MicroSD Card

  1. Download Raspberry Pi Imager from the official website: https://www.raspberrypi.org/software/
  2. Insert your MicroSD card into the card reader and connect it to your computer
  3. Open Raspberry Pi Imager, select Raspberry Pi OS from the list of operating systems
  4. Choose the storage device (your MicroSD card) and click Write
  5. Wait for the process to complete. Once finished, eject the card safely from your computer

2 Enable SSH and VNC on Raspberry Pi OS

  1. Insert the MicroSD card into the Raspberry Pi 4 and connect it to your monitor, keyboard, and mouse
  2. Power on the Raspberry Pi
  3. After the Raspberry Pi OS loads, open the Terminal on the Raspberry Pi

  4. To enable SSH:

    sudo raspi-config

    Navigate to Interfacing Options > SSH > Enable

  5. To enable VNC:

    From the same raspi-config menu, navigate to Interfacing Options > VNC > Enable

  6. Exit the configuration tool by selecting Finish and rebooting your Raspberry Pi

3 Find the Raspberry Pi's IP Address

  1. Once the Raspberry Pi has rebooted, open the Terminal

  2. Type the following command to find the IP address:

    hostname -I

  3. Note down the IP address; you will need it to connect remotely

4 Connect to the Raspberry Pi via SSH

  1. On your computer (Windows, macOS, or Linux), open an SSH client
  2. Windows: Download and install PuTTY from putty.org
  3. macOS/Linux: Use the built-in terminal
  4. In the SSH client, enter the Raspberry Pi's IP address
  5. For the username, enter: pi
  6. For the password, enter the default: raspberry
  7. Click Open (or press Enter on macOS/Linux). You should now be connected to the Raspberry Pi via SSH

5 Connect to the Raspberry Pi via VNC

  1. On your computer, download and install RealVNC Viewer from realvnc.com
  2. Open RealVNC Viewer and enter the IP address of the Raspberry Pi
  3. Click Connect
  4. When prompted, enter the username (pi) and password (raspberry)
  5. You should now see the Raspberry Pi desktop environment on your computer

For security, remember to change the default password after your first login using the passwd command in the terminal.

Conclusion

You've now successfully set up your Raspberry Pi 4 with remote access via both SSH and VNC. This configuration allows you to work with your Raspberry Pi without needing direct access to a monitor, keyboard, or mouse, making it ideal for headless setups and remote projects.

With SSH, you can execute commands remotely, while VNC provides full graphical access to the desktop environment. This combination gives you complete control over your Raspberry Pi from any computer on your local network.
